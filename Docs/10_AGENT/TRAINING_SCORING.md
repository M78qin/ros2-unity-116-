生成时间：2026-11-03 23:12　对应界面：`30_界面与交互/UI_二期面板/MissionRoot`（实训任务台）

> 定位：这是**训练过程评分原型**，不是正式考核系统；所有事件来自 UI 侧（步骤按钮、提示展开、安全校验状态），

## 1. 依据（公开框架，正式引用需补文献）

- 形成性评价（过程反馈）与终结性评价（结果等级）结合：训练中给提示与薄弱项，训练后给等级。
- 技能操作类考核通用三维：**步骤合规 / 安全 / 效率**，另加**独立性**（提示依赖）。
- 安全类操作一票否决：涉及断电、验电、绝缘的步骤被跳过，本次不计分。

## 3. 评分模型（100 分）

| 维度 | 权重 | 计分规则 |
|---|---|---|
| 过程合规 | 40 | 8 步，每步完成 +5；顺序违规每次 −5（单步最低 0） |
| 安全 | 30 | 九项安全校验全绿 30；任一项未通过/被忽略 −10；急停触发 −10（并记事件） |
| 效率 | 20 | `20 × min(1, T_ref / T)`，`T_ref` = 基准时长（专家演示或熟练组中位数，待定）；`T` = 本次总时长 |
| 独立性 | 10 | 无提示 10；每用一次提示 −2，最低 0 |

**一票否决**：跳过"断电 / 验电 / 绝缘"任一步 → 本次 0 分，记录 `SAFETY_VIOLATION`。

等级：≥85 优秀；70–84 良好；60–69 合格；<60 不合格。反馈输出"薄弱步骤 Top3 + 建议"。

## 4. 与论文故事（第 4 章）的对应

- 系统实现：双主面板 + 状态监控 + 双向控制边界 + 评分原型（本章工作量主体）。
- 实验设计（小样本初步验证）：新手组 vs 熟练组，指标 = 总时长、步骤违规次数、提示次数、得分；
  统计 = 均值±标准差 + 独立样本 t 检验（n<6 时只报告描述统计，不硬套显著性）。
- 结论口径：证明"虚实联动界面支持训练过程量化"，不宣称教学效果提升（无对照教学实验）。
